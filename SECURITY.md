# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting feature for this repository, if available. If private reporting is not enabled, contact the repository maintainer privately through GitHub before disclosing the issue publicly.

Include the affected version, impact, reproduction steps, and any relevant logs. Do not include real network traffic captures, credentials, tokens, personal data, or other sensitive information.

The maintainer will acknowledge reports as soon as reasonably possible and coordinate a fix and disclosure. This project is maintained on a best-effort basis; no formal response-time guarantee is currently offered.
